# OutLab API contract v1

Language: every `/api/*` request may send `X-OutLab-Lang: tr|en` (default `tr`; any other value falls back to `tr`). All user-facing `detail` messages, warnings, sensor labels and candidate reasons are returned in that language, including errors raised by the localhost/size boundary middleware.

Local application: Python FastAPI on 127.0.0.1:8765 serves Vite build; Vite development proxies /api. UI React/TypeScript. No cloud upload, no API keys. All application code inside this folder. Personal sibling files never committed.

POST /api/inspect JSON `{sources:[{name,text}]}` -> `{files:[{name,kind,columns,preview,tag,timeColumn,valueColumn,timeUnit,warnings}]}`. kind csv|raw|gpx|info|unsupported; preview array of string arrays; timeUnit auto|s|ms|us|iso. All fields present. `name` is ID, reject duplicate filenames. Exclude metadata counters from value guess. Raw EmotiBit packet file may be detected but must be refused with parser guidance if accurate per-sample timing cannot be reconstructed. Info JSON accepted for documentation, not magic timestamps.

POST /api/import JSON `{sources:[{name,text}],mappings?:[{name,tag,timeColumn,valueColumn,timeUnit}]}` -> Dataset. Multiple known sensor value columns in wide CSV import separately; explicit mapping narrows to selected channel. Reject mixed relative and absolute sensor clock domains. Never independently zero each sensor (preserve relative differences). Reject invalid timestamps visibly; return row counts/warnings. GPX segments/gaps retained.

Dataset `{channels:Channel[],track:TrackPoint[],sources:Source[],sensorOriginEpoch:number|null,gpxOriginEpoch:number|null,duration:number,warnings:string[]}`. Channel `{id,tag,label,unit,points:Point[],sampleRate:number|null,sourceId,quality:{totalRows,validRows,invalidRows,duplicates,gaps,flat:boolean,warnings:string[]}}`. Point `{t:number,v:number}`. TrackPoint `{t,lat,lon,ele?:number,segment:number}`. Sensor point t in seconds since COMMON earliest sensor timestamp; GPX point t in seconds since first GPX timestamp. Sources `{name,sha256,rows:number,kind:string,warnings:string[]}`. SensorOriginEpoch null for device-relative times, otherwise earliest absolute timestamp seconds. gpxOriginEpoch first absolute GPX timestamp. Duration max sensor t and GPX local t. No unbounded extrapolation.

POST /api/analyze JSON `{dataset:Dataset,options?:{quality?,motionWindows?,robustness?},config:{baselineStart:number,baselineEnd:number,zThreshold:number,minDistance:number,motionThreshold:number}}` -> Analysis. Analysis `{method:string,version:string,parameters:object,points:AnalysisPoint[],events:Candidate[],warnings:string[],metrics:{sampleRate:number|null,edaSamples:number,flaggedPercent:number,baselineMedian:number|null,baselineMad:number|null}}`. AnalysisPoint `{t,raw,clean:number|null,tonic:number|null,phasic:number|null,motion:number|null,flagged:boolean}`. Candidate `{id,t,amplitude:number,score:number|null,reason:string,flagged:boolean}`. Source raw values unchanged. Movement flag heuristic does not prove artifact and is never silently erased/interpolated. Segment gaps before filtering. Scientific components via explicit NeuroKit2 highpass method with version; candidate robust z is exploration heuristic, never diagnosis or validated SCR count. No HR or HRV calculation from raw PPG. Minimum valid baseline; fail clearly instead of invented scores. Config applied and returned exactly.

GET /api/health -> `{status:'ok',version:string}`. Errors JSON `{detail:string}` with HTTP 400/422. Body limits and localhost origins. Production API same origin with Host/Origin checks.

UI alignment: videoTime session = rate*videoSeconds + offset. Rate=1 single anchor; two anchors solve affine drift. Mark manual unverified until an anchor applied with reason and uncertainty. GPX t session = GPX t + gpsOffset; automatic epoch difference only when both origins valid. Sensor is reference axis. Preserve original timestamps in source text included in portable local project JSON. Imported real data not put in repository. Up to 4 videos per project (`videos: VideoTrack[]`), each `{id,name,size,lastModified,duration?,offset,rate,verified,anchors,uncertainty,reason}` with its own affine mapping. Video File objectURL only; reconnect after reload (same name/size/lastModified reconnects its slot and keeps its mapping), show name/duration and explain it. The visible video is the chosen one if it covers the playhead, otherwise a connected video that does; playback continues into the next covering video at a video end. Legacy single-video projects (`videoFile` + `sync.video*`) migrate into `videos[0]`. Synthetic demo distinctly labeled.

Project frontend schema `{schemaVersion:1,participant,title,dataset,analysis,config,sync,videos,events,sourceTexts,audit,isDemo}`. Notes and all edits persist in IndexedDB; downloadable project JSON contains source texts, hashes, analysis, sync, audit, interview notes, no video binary. Event interview records with pre/post seconds, selection status, free narrative, valence/arousal optional values, codes, recall date. Participant mode hides graphs/candidate labels, neutral open prompt, contiguous clip playback within bounded video time, no automatic emotion inference.


Optional methods (all off unless `enabled: true`; core results are unchanged in "flag" mode): `quality {minUs=0.05,maxUs=60,maxSlope=10,temperatureTag:T0|T1|TH|null,tempMin=30,tempMax=40,transitionSeconds=5,flatSeconds=10,flatRangeUs=0.001,windowSeconds=5,prefilterSeconds=2,action:flag|exclude}`, `motionWindows {windowSeconds=2,k=3,useGyro,useSpeed,gpsOffset}`, `robustness {decompositions:[highpass|smoothmedian|cvxEDA],peakMethods:[neurokit|kim2004|gamboa2008|nabian2018|vanhalem2020],minAmplitudeUs=0.05,toleranceSeconds=2}`. Response adds `extras.{quality,motionWindows,robustness}`, `points[].qualityInvalid|motionWindow` and `events[].checks{qualityInvalid,motionWindow,support{count,total,configs}}` only for enabled methods; `parameters.optionalMethods` records them. Manual annotations (`Project.annotations[]`: coder, start, end, label artifact|valid|unsure, reason, note) and their agreement statistics are computed in the frontend and never change the analysis.
